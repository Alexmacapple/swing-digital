# AnswerPanel

Panneau question-réponse pour les moteurs et les agents : titre, réponse et tableau.

## Où il sert

Pages : `espaces-augmentes.html`, `experience-monroe.html`, `experiences-series.html`. La version anglaise (`en/`) reprend la même structure.

## Structure

Racine : `.seo-geo-panel`.

Éléments : `.seo-geo-panel__answer`, `.seo-geo-panel__inner`, `.seo-geo-panel__table`, `.seo-geo-panel__title`.

## Ce que fournit l’intégrateur

- les textes : titres, paragraphes, crédits, dans la langue de la page (`lang`)

## Règles

- Titres en `type-title` ou `type-title-xl`, graisse 900 ; corps en `type-body`.
- Texte `paper` seulement sur `ground-pink`, `ground-red`, `ground-navy`, `ink` ou une image voilée par `overlay-45` au minimum.
- Crédits photo en `type-credit`, jamais en `decor-gold` sur fond clair.
