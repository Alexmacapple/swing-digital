Logos des partenaires, financeurs et médias, copiés de `src/img/partners/`. Ils servent dans `PartnersLogos` et dans les bandeaux `__logos-bar` des pages projet. Les PNG sont posés tels quels sur `paper` ou `ink` ; la variante `__logo--invert` les passe en blanc sur fond sombre. `swing-digital.png` et `swing-digital-hd.png` sont les logos image de Swing Digital, utilisés dans les bandeaux de logos de `AwardsHero` et `PortraitSeriesHero` : l'en-tête garde le logotype typographique `| Swing Digital |`.
