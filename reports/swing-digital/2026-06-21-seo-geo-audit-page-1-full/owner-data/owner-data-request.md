# Demande de données propriétaire - swing.appmiweb.com/#page-1

Ces données servent à distinguer ce qui est observable publiquement de ce qui nécessite un accès propriétaire. Ne pas utiliser d’outil payant ou crédité sans validation explicite.
## Données demandées

### Google Search Console
- Export demandé : Performance export for the audited property covering queries, pages, countries, devices, CTR, clicks, impressions, and average position.
- Utilité : Search visibility, query fit, CTR, and page-level opportunities cannot be proven from public HTML alone.

### GA4
- Export demandé : Landing page, source/medium, conversion, engagement, and AI-assistant referral reports for the same audit window.
- Utilité : Public tools cannot verify visits, conversions, or business impact.

### Bing Webmaster Tools
- Export demandé : Search performance, crawl/indexing issues, IndexNow status, and AI Performance data if available.
- Utilité : Bing/Copilot and IndexNow evidence requires owner access or explicit exports.

### server logs
- Export demandé : Bot/user-agent logs for Googlebot, Bingbot, OAI-SearchBot, GPTBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, PerplexityBot, and Perplexity-User.
- Utilité : Crawler access, WAF blocks, and fetch behavior need log evidence.

### Cloudflare Analytics
- Export demandé : Traffic, cache, WAF/firewall, bot, and response status analytics for audited URLs.
- Utilité : Cache/CDN behavior and blocked crawlers should be verified by owner-side telemetry, not bypass attempts.

## Consentement outils payants

Par défaut : demander avant d’utiliser Haloscan, Semrush, Ahrefs, DataForSEO, Similarweb, SerpApi ou tout outil consommant des crédits.
