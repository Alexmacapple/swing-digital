# Version EN — état de traduction

Le lot couvre les issues #47 à #54 dans le périmètre local : architecture
`/en/`, sélecteur FR/EN, 29 routes, textes visibles, attributs accessibles,
données structurées et transcriptions embarquées.

Le contrôle automatisé vérifie :

- l’existence et la réponse locale des 29 routes ;
- la langue HTML, les canoniques et les alternates bilingues ;
- le sélecteur de langue clavier ;
- la conservation du nombre de transcriptions entre FR et EN ;
- le cache-buster CSS anglais et les chemins d’assets partagés.

La traduction initiale est produite par lots structurés à partir des sources
françaises et doit encore recevoir la relecture éditoriale de Stéphanie avant
une annonce publique. Cette relecture ne bloque pas le fonctionnement local ni
la recette technique ; elle est la dernière étape humaine de qualité du texte.
